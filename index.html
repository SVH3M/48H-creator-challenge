Connect
Firebase
First.

This tracker uses Firebase Realtime Database so both you and your friend see updates instantly — no link sharing needed. Free to set up, takes about 2 minutes.

01
Go to console.firebase.google.com → Create a new project (any name). You can skip Google Analytics.
02
In the left sidebar → Build → Realtime Database → Create database → pick any region → start in test mode (allows read/write for 30 days — fine for a private race).
03
Go to the gear icon → Project Settings → scroll to Your apps → click the </> web icon → register the app → copy the firebaseConfig object shown.
04
Open index.html in a text editor → find FIREBASE_CONFIG near the top of the <script> tag → paste your values in, replacing each YOUR_... placeholder → save and push to GitHub.

Both you and your friend just need to open the same GitHub Pages URL — no extra setup on their end. The scoreboard will sync automatically within a second of any change.

The Rules

Read
Carefully.

A bet is only a bet if both sides are clear on the terms. This is the contract. Once it's signed, the only way out is to win — or to lose.

Disputes? The middleman holds the deposit. The timeline is the ledger. The countdown is the judge.

01
One Video Per 48 HoursEach runner must publish at least one video by the end of every 48-hour window. Window 1 closes at end of day 2 from race start.
02
$100 Monthly StakeBoth runners deposit $100 to the middleman at the start of each month the race is active. No deposit, no race that month.
03
First Miss = EliminatedA missed deadline ends the runner's race immediately. No make-ups, no make-good videos.
04
Winner Takes The PotThe middleman releases the entire accumulated deposit to the surviving runner upon elimination of the other.
05
Double Miss = Race VoidedIf both runners miss the same deadline, the race is voided and the middleman returns deposits proportionally.
